# 夜班櫃台（night-desk）— 設計文件

> 狀態：草稿，2026-07-31。實作前先看這份。
> 一句話：把玩家從「讀守則的房客」翻轉成「被守則約束的夜班櫃台」，
> 讓「這條規則能不能信」從背景知識變成每分每秒的判斷。

## 1. 現況診斷：為什麼現在不好玩

`scenes/hotel.js` 的內容品質很好（四本守則、七結局、drift），但玩法上是：

- 所有 action 都是「看 X／翻 Y／去 Z」——觀察與移動。
- 玩家的工作 = 把每個按鈕點一遍，把文本讀完。
- 守則撿到就全解鎖，躺在左欄當背景，**沒有任何一個決定需要核對守則**。
- 結局由「軌跡累積」（drift、去過哪、撐到幾點）決定，不是由「判斷」決定。

玩家是讀者，不是判斷者。點選項只是翻頁。

## 2. 新玩法骨架

你是深夜飯店的夜班櫃台。23:00 上班，06:00 交班，共三晚。

每晚循環：

1. **開工**：抽屜裡有今晚的守則（官方版）＋交班簿（前任們的手寫記錄）。
2. **事件上門**：一連串事件依時間序找上你——客人入住、電話、敲門、投訴、監視器異常。
3. **處置**：每個事件給 2–4 個處置選項。**哪個選項是對的，取決於你信哪份文件。**
4. **交班結算**：06:00 結算。判斷的後果不一定當晚結算——
   最常見的呈現方式是：**隔天晚上，守則上多了一條**。

關鍵機制：**資訊來源複數且互相矛盾**

- 官方守則：飯店印的，每晚可能換版（新增、修改、字跡不同）。
- 交班簿：前任手寫，語氣像人。會直接說「別信守則第 X 條」。
- 兩者矛盾時沒有系統提示，玩家自己選邊。選錯的代價延遲呈現。

判斷錯誤**不是 game over**，是世界變得更不對勁。恐怖從機制裡長出來，不是寫出來的。

## 3. 資料結構

沿用現有 scene contract（engine.js 不用動），新機制收進 scene 內：

```js
// 守則：每晚一個版本，條目帶「來源」與「被篡改」屬性
ruleset: {
  night1: [ { id, text, source: "official" } ],
  // 之後的夜晚可以 patch：新增條目、覆寫條目、字跡不同（顯示樣式）
}

// 交班簿：另一份規則來源，跨晚累積
handoverNotes: [ { id, text, night } ]

// 事件：值班的核心。時間窗觸發，強制回應（有時限；超時不處理也是一種處置）
events: [
  {
    id, night, windowMin: [startMin, endMin],
    prompt,                    // 事件敘述（進 narrative stream）
    choices: [
      { id, label, resolve(state) // 後果：narrate、flag、改隔晚守則
      }
    ],
    timeoutChoice,             // 超時預設處置
  }
]
```

事件用現有 `derive()` 推進：時鐘進入 windowMin 就把事件推進 narrative，
actions 換成該事件的處置選項；選完或超時，回到待機敘述。
state migration：新版本 bump `STORAGE_PREFIX`（v2 → v3）。

## 4. 第一晚內容

### 4.1 官方守則（櫃台守則 v1）

1. 上班時間 23:00–06:00。不要離開櫃台超過五分鐘。
2. 客人要入住，先核對登記簿：簿上有名字的，給鑰匙；沒有的，請他明天再來。
3. 電梯面板沒有 4 樓。有客人問起，回答「本館沒有 4 樓」。不要解釋。
4. 午夜之後，不要為任何人開大門。穿本館制服的員工除外。
5. 電話響三聲之內要接。超過三聲還在響，不要接。
6. 客人投訴房間，回覆「明早為您處理」。不要親自上樓。
7. 登記簿上 704 那一格，不要寫任何東西。

### 4.2 交班簿（第一晚拿到，前任字跡）

- 「守則第 4 條，穿制服的也不能開。相信我。」
  （旁邊另一種字跡：可以開。他要進來的時候，你攔不住。）
- 「704 那格我已經寫了。你最好不要擦掉。」
- 「三點到四點之間，監視器如果有人站在大門外，那是正常現象。不要看超過十秒。」

### 4.3 事件池（第一晚，正常→微異常漸變）

1. **23:20 醉客入住**：登記簿沒他的名字。
   拒絕＝照規則，他罵罵咧咧走了。
   收下＝你翻開登記簿寫他的名字——發現那行字已經在了，字跡是你的。
2. **23:50 客人問 4 樓**：照本宣科＝他走了。
   解釋＝他繼續問：「但我朋友住 402，他昨晚還打給我。」
3. **00:30 大門外有人影敲門**，看不清穿什麼。
   不開＝他敲一陣子，走了。地毯濕了一塊。
   開＝他進來，站在櫃台前不說話。你低頭，登記簿 704 那格濕了。
4. **01:15 電話響兩聲**：女人問「704 的客人睡了嗎」。
   回答＝「幫我跟他說，鑰匙不用還。」掛斷。
   沉默掛斷＝五分鐘後電話又響，這次響了七聲，一直響。
5. **02:40 監視器：大門外站著人。**
   看超過十秒＝你切到櫃台畫面時，那個人影在你背後。回頭，沒人。
   十秒內移開＝沒事。但你發現你數了。
6. **03:30 704 的客人下樓投訴**：「隔壁房間在學我說話。」
   「明早為您處理」＝他點點頭上樓了。你注意到登記簿 704 那格是空的。
   上樓查看＝（違反規則 6）走廊很長，你不記得怎麼回來的。
7. **05:00 穿制服的同事進門**：「我來接班。」
   守則說 06:00 下班。交班簿說穿制服的也不能開。
   給他鑰匙＝他接過去，笑著說「你可以走了」。你不記得你走到哪。
   請他等＝他笑著說「你做得很好」，在大廳沙發坐下，等到六點。
   你不確定哪個是對的。這就是重點。

## 5. 三晚曲線

- **第一晚**：建立規則、單一矛盾（規則 4 vs 交班簿）。結尾埋下 704。
- **第二晚**：守則換版。多了幾條新的，其中一條字跡不同、編號跳號。
  你昨晚的行為變成新條目（「若你昨夜曾為任何人開門，請勿閱讀本條」）。
  交班簿上出現「不是你寫的、但你記得你寫過」的頁面。
- **第三晚**：所有文件互相矛盾到極致。登記簿上你的名字出現在 704 那格。
  最後一個事件是「你自己」走進大門說要入住——核對登記簿：簿上有名字。

結局（初稿）：
- **交班**：三晚都撐住，06:00 把鑰匙交給真正的早班。
- **被收編**：你的名字進了 704，你成為下一晚事件池裡的一個事件。
- **站在門外的人**：你成了午夜敲門的那個人影，下一任櫃台的交班簿上多了一條關於你的記錄。
